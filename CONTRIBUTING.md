# Contributing to Awesome Cheap Flights & Travel Hacks ✈️🌍

Thank you for your interest in contributing! This curated repository aims to be the most comprehensive, accurate, and transparent resource for budget travelers, digital nomads, and developers seeking 0% markup travel intelligence.

---

## 🌟 How to Contribute

We welcome:
- New flight route hacks, secret transit layovers, and repositioning techniques.
- Verified budget hotel hubs and digital nomad co-living spaces.
- Updates on airline passenger rights and compensation legislation (EU261, UK261, US DOT, ANAC Brazil).
- High-quality open-source travel datasets, scraping tools, and travel APIs.
- Fixes for broken links or outdated airline policies.

---

## 📋 Contribution Guidelines

1. **Quality over Quantity:** Only submit resources you have personally tested or verified with official airline/government documentation.
2. **Transparent & Free First:** Tools with hidden booking fees, subscription paywalls, or predatory upsells will not be accepted.
3. **Proper Markdown Formatting:**
   - Link text should be clear and descriptive.
   - Use standard formatting matching the existing tables and lists in `README.md`.
4. **No Spam or Unauthorized Affiliate Links:** Submissions containing personal masked affiliate links or multi-level referral spam will be closed immediately. All core platform integrations are managed via [Prymeo](https://www.prymeo.com) by [Lucebra LLC](https://www.lucebra.com).

---

## 🚀 Step-by-Step Submission Process

1. **Fork** the repository to your own GitHub account.
2. Create a new descriptive branch:
   ```bash
   git checkout -b add-tokyo-transit-hack
   ```
3. Make your edits to `README.md`.
4. Commit your changes with a clear commit message:
   ```bash
   git commit -m "feat(hacks): add Haneda to Narita dual airport repositioning guide"
   ```
5. Push to your branch:
   ```bash
   git push origin add-tokyo-transit-hack
   ```
6. Open a **Pull Request (PR)** against the `main` branch. Provide a brief summary of what you added and why it benefits the global traveler community!
